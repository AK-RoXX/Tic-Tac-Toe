# ❌ Tic-Tac-Toe ⭕

A Tic-Tac-Toe game built with **React** and **Tailwind CSS**. Features the Minimax algorithm and a local multiplayer mode.



## 🚀 Features

- **Two Game Modes**: 
  - **vs Friend**: Local multiplayer with customizable player names.
  - **vs Computer**: Play against an unbeatable computer (Minimax Algorithm).
- **Scoreboard**: Tracks win streaks for both players/AI.
- **Dynamic UI**: 
  - Centered, dark-mode design.
  - Winning line highlighting.
  - Interactive button animations.
- **Sound Effects**: Audio feedback for moves, wins, and draws.

## 🛠️ Tech Stack

- **Framework**: React (Vite)
- **Styling**: Tailwind CSS v4
- **Algorithm**: Minimax (for AI decision making)
- **State Management**: React Hooks (`useState`, `useEffect`)
